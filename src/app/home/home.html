  1. Tap the Share button in the browser's toolbar.
  2. Scroll down and tap Add to Home Screen.

} @case ('android') {
  1. Open the browser's menu ().
  2. Tap Add to Home screen or Install app.
  3. Confirm with Add or Install.

  1. Open the File menu, or the Share button.
  2. Choose Add to Dock.

In Chrome or Edge, click the install icon at the right end of the address bar, or open the browser's menu and choose Install scorekeeper (in Chrome under Cast, save and share).

Not every browser can install web apps. Even without installing, scorekeeper keeps working offline once it has been opened. So don't close that tab!
